First time? Compute Canada login & port forward

Run these from your local machine. The UI server runs on the Compute Canada login node; the SSH tunnel exposes it to your browser at http://localhost:5050. 

# 1. SSH in (replace USER and CLUSTER with your account)
ssh -L 5050:localhost:5050 USER@vulcan.alliancecan.ca

# 2. On the login node:
cd /scratch/USER/Agentic
source /scratch/USER/agentic/bin/activate
python ui/app.py

# 3. Open http://localhost:5050 in your local browser
